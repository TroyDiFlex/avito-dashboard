# Подключение двух Google-таблиц

Скрипт читает только «Статистика» и листы, начинающиеся с «Детализация». Он не изменяет таблицы и не создаёт триггеров. Установка выполняется один раз вручную владельцем Google-аккаунта.

1. Создайте отдельный проект на https://script.google.com и вставьте содержимое [Code.gs](Code.gs).
2. В настройках проекта добавьте свойство `SPREADSHEET_IDS`. Значение — JSON-массив из двух ID таблиц: `["ID_ПЕРВОЙ_ТАБЛИЦЫ", "ID_ВТОРОЙ_ТАБЛИЦЫ"]`. ID — часть адреса между `/d/` и `/edit`.
3. Включите отображение `appsscript.json` в настройках и замените его содержимым [appsscript.json](appsscript.json). Манифест включает Google Sheets API с разрешением только на чтение (`spreadsheets.readonly`).
4. Выберите функцию `initialize` и запустите. Разрешите чтение. У аккаунта должен быть доступ к обеим таблицам.
5. В настройках проекта, в свойствах скрипта, скопируйте созданный `SYNC_TOKEN`. Не публикуйте этот ключ и не добавляйте его в GitHub.
6. Выберите «Начать развертывание» → «Новое развертывание» → «Веб-приложение». Выполнять от вашего имени, доступ — «Все». Хотя адрес доступен извне, данные возвращаются только POST-запросу с правильным ключом. Если политика организации запрещает такой вариант, потребуется другой способ подключения.
7. Скопируйте URL, заканчивающийся на `/exec`, и укажите его вместе с `SYNC_TOKEN` в настройках дашборда.
8. Нажмите «Обновить данные». Проверьте последний период и замечания к данным.

Запуск `initialize` повторно сохраняет существующий ключ. При изменении кода обновляйте опубликованное развертывание. Для смены ключа измените `SYNC_TOKEN` в свойствах и настройках дашборда.
