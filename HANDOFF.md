# Текущее состояние · 9 сентября 2026

Главный экран переработан в недельный аудит всех 20 запрошенных метрик плюс стоимость контакта. Все графики видимы в четырёх тематических группах; точные значения по неделям доступны в таблицах под группами. Значения карточек относятся к последней календарной неделе выбранной истории, сравнение — строго с предыдущей неделей. Пропуски не подменяются нулями или старыми отчётами.

Основной опубликованный интерфейс — GitHub Pages: https://TroyDiFlex.github.io/avito-dashboard/ . Публикация через main, каталог docs, сборка npm run build:pages. Существующий Sites manifest сохранён, новый сайт не создаётся.
