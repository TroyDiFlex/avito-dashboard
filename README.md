# ПИК · Аналитика Авито

Тёмный дашборд статистики подразделений и недельной истории объявлений. Рабочий интерфейс публикуется на GitHub Pages, обновление двух исходных Google-таблиц выполняется только по кнопке. Исходные таблицы не изменяются.

## Что реализовано

- Все показатели листа «Статистика», недельные графики и сопоставление периодов.
- Сравнение подразделений в абсолютных значениях или с общей базой 100%.
- Поиск и фильтрация объявлений, небольшие графики, полная история объявления, сравнение до четырёх объявлений.
- Сохранение основных фильтров на устройстве.
- Разбор нескольких форматов детализации, проверка конверсий, дат, дубликатов и сверка со статистикой.
- Серверный код подключения Apps Script и ручного обновления. Новая версия становится активной после записи всех частей; предыдущая сохраняется при ошибке.
- Агрегация по неделям, месяцам и годам; средние и медианные значения для объявлений.
- Выделение складского артикула из названия и настраиваемая ссылка «Найти объявление».

## Важные границы

Приложение собрано и проверено автоматически. До подключения реальных Google-таблиц интерфейс показывает явно помеченные демонстрационные данные. Браузерная и визуальная проверка не выполнялись: управление браузером запрещено без отдельного разрешения.

Код публичный. XLSX, исходные данные, нормализованный снимок и ключи исключены из Git. В версии GitHub Pages URL Apps Script, ключ подключения и загруженный снимок хранятся только в браузере пользователя. Для снимка используется IndexedDB, поэтому объём истории не ограничен малым лимитом localStorage.

Опубликованный сайт: <https://TroyDiFlex.github.io/avito-dashboard/>.

## Локальная разработка

Node.js 22.13+; npm.

```sh
npm ci
npm run dev
npm run build:pages
npm test
```

Для получения начального снимка из Excel (read-only, Python с openpyxl):

```sh
python scripts/extract.py /path/to/source-xlsx private/raw.json
node scripts/build-snapshot.mjs
```

Для локального хранилища используется D1. Миграции находятся в `drizzle/`; примените их перед проверкой подключения. Не запускайте сервер на публичном адресе без защиты доступа.

Инструкция Google Apps Script: [apps-script/SETUP.md](apps-script/SETUP.md).

## Расчёт показателей

- Статистика и детализация — независимые источники; расхождения отображаются, не скрываются.
- Показы, просмотры, контакты, избранное, расходы и маржа суммируются по выбранным периодам.
- Конверсии и стоимость контакта/просмотра вычисляются из сумм. При нулевом знаменателе — нет данных.
- Рейтинг, отзывы, время ответа, состояния объявлений, склад — значение на последнюю выбранную дату. Пропуск не заменяется более старым значением.
- ROI сохраняет значение исходного листа на последнюю дату. Формула и рекламная атрибуция требуют подтверждения.
- Дата — конец отчётного периода, не отдельный день. Пропуски в истории не равны нулю.
- Годы заголовков статистики восстанавливаются по датированной детализации и календарным переходам; старую историю нужно подтвердить.
- Маржа подразделения не распределяется по объявлениям.

## До первого рабочего обновления

1. Установить Apps Script по [инструкции](apps-script/SETUP.md).
2. Ввести URL веб-приложения и `SYNC_TOKEN` в настройках дашборда.
3. Нажать «Обновить данные» и проверить последний период и список замечаний.
