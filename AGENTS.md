# Deployment

- The only production host for this project is GitHub Pages.
- Publish only to `https://troydiflex.github.io/avito-dashboard/` from `main/docs`.
- Never create, register, copy, deploy, or migrate this project to OpenAI Sites, ChatGPT Sites, Cloudflare Workers, Vercel, or another host.
- Build with `npm run build:pages`, commit `docs/`, and push `main` to the GitHub `origin` remote.
- Do not change the hosting target without an explicit user request naming the new host.
